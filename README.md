# MythicalGM
A Discord bot to roll dice and handle the general mechanics of Mythic 2E.
 
 ***DISCLAIMER*** Since it is illegal to reproduce copyrighted content, I should say that this bot has no content from the Mythic 2E guides, it simply handles the chaos factors and dice rolling. Support the original release.


**COMMAND LIST**

/diceroll - standard diceroll. Takes the shape of the dice as parameter
/fatecheck - Fate check following the Oracle's rules. Requires a chaos factor (int 1-9) and a likelyhood that adjusts the thresholds for successes
